# NAO 右臂双自由度俯视轨迹模拟器

## 运行

```bash
conda activate torch-py311
cd ~/桌面/gp/nao_right_arm_2d_simulator
python nao_right_arm_2d.py
```

已按 `torch-py311` 环境验证。程序界面使用该环境的 Tkinter，无需额外安装依赖。程序提供手端目标输入、画布点选、播放/暂停、时间拖动和 CSV 导出。

## VIA POINTS

1. 在“画布点选”中选择 **点击添加 VIA POINT**。
2. 按希望经过的顺序直接点击画布，紫色 `V1`、`V2`……会立即显示。
3. 点击 **规划轨迹**。最多支持 12 个中间点。

程序在总运动时长内自动均匀分配各 VIA 点的到达时间。例如 4 秒轨迹有三个 VIA 点时，到达时间自动设为 `1 s`、`2 s`、`3 s`。可用 **撤销最后一个** 或 **清空全部** 修改点列。程序精确经过各点，并保持中间点处的速度连续；起点与终点速度、加速度为零。

**手端轨迹模式**在无 VIA 点时走一条直线，有 VIA 点时通过各点形成平滑的笛卡尔空间曲线；**关节平滑插值模式**在各点间平滑插值两个关节角。两种模式均检查所有轨迹采样点的关节限位。由于模型只有两个自由度，点击确定 `X, Y` 后手端方向由关节解确定。CSV 的 `waypoint` 列标记 `起`、`V1`、`V2`、`终`。

## 旋转画布

单击 **旋转画布 90° ↻**，整个网格、坐标轴、可达区域、机器人和轨迹会绕 `O₀` 顺时针旋转 90°；连续单击可在 `0° → 90° → 180° → 270° → 0°` 之间循环。右上角显示当前视图角度。旋转只影响显示，机器人坐标、关节角、轨迹和 CSV 数值不会改变。旋转后继续点击设置起点、终点或 VIA POINT 时，程序会自动进行逆旋转，得到正确的原始机器人坐标。

绘图区会随窗口尺寸自动缩放并居中完整工作区，保持 X/Y 等比例，避免机械臂几何形状失真。网格延伸到整个画布可用区域；图例与旋转角度放在画布上方的独立状态栏中，因此不会遮挡坐标、轨迹或 VIA POINTS。

界面从 Tkinter 可用字体中依次选择 **Noto Sans CJK SC**、**Microsoft YaHei（微软雅黑）**、**WenQuanYi Micro Hei** 或 **PingFang SC**，统一用于控件和画布文字。正文为 13 磅、标题 20 磅、画布刻度 12 磅；左侧设置栏可滚动，缩小窗口时仍可访问全部设置。若 Tkinter 找不到这些中文字体，程序会提示安装字体。

不打开图形界面也能验证核心计算：

```bash
python -m unittest -v test_nao_right_arm_2d.py
```

## 模型

按附图的俯视坐标，躯干原点为 `O₀=(0,0)`，`+X` 向右、`+Y` 向上。肩关节 `S=(0,-113)` mm（图示 `98+15`），肩到肘 `L₁=105` mm。肘到腕/手部参考点的两个共线长度为 `55.95` 和 `57.75` mm；这两段之间没有新增自由度，所以两自由度计算中的第二杆总长 `L₂=113.70` mm。画面将两段分别着色。

角度定义：`θ₁=RShoulderRoll` 是上臂相对于 `+X` 的逆时针角，`θ₂=RElbowRoll` 是第二杆相对于上臂的逆时针角。[NAO 官方坐标约定](https://doc.aldebaran.com/2-8/naoqi/motion/almotion.html)中机器人 `X` 向前、`Y` 向左、`Z` 向上；附图俯视坐标可取 `x₀=−Y`、`y₀=X`，所以绕 `+Z` 的正转角在图中为逆时针。此平面等效模型把右臂沿 `+X` 伸直作为零位；其余 NAO 关节保持固定，不模拟三维耦合。手部参考点：

```text
x = L₁ cos(θ₁) + L₂ cos(θ₁+θ₂)
y = -113 + L₁ sin(θ₁) + L₂ sin(θ₁+θ₂)
```

程序采用附图表 3.1 的关节限位：`RShoulderRoll ∈ [−70°, 18°]`，`RElbowRoll ∈ [2°, 88.5°]`。第一张图将肩部下限标为 `−76°`，与表格不一致；本程序采用表格中较保守的 `−70°`。逆运动学用余弦定理求解，并只接受肘角为正的右臂分支。起点、终点及轨迹各采样点都须满足限位，超限时给出关节名称和角度。

手端在**纯几何**下可达以肩为圆心、半径 `8.70–218.70` mm 的圆环；实际允许范围还受上述角度限制，画布中用浅绿色表示。无 VIA 点的笛卡尔直线轨迹会解析检查整条线段是否穿过纯几何不可达区；带 VIA 点的曲线和关节模式按最多约 1 mm 的相邻手端采样间距检查。轨迹使用五次多项式插值：无 VIA 点时为标准 `10u³−15u⁴+6u⁵` 时间律；有 VIA 点时按各点的时间和速度条件分段插值，使中间点连续通过。

这是几何与轨迹演示，尚未加入自碰撞、执行器速度/力矩、动力学或其他关节耦合约束。CSV 中的角度列直接对应 `RShoulderRoll`、`RElbowRoll`；速度由采样点的中心差分得到。
