# 机器人书写 Q-learning：自由试错训练与严格执行校验

依据本目录论文 Xu 等《Robots Learn to Write via Human–Robot Interaction》（CAC 2020，DOI:10.1109/CAC51589.2020.9326574）实现表格 Q-learning，使用 α=0.5、γ=0.9、ε=0。训练允许真实改变仿真状态的试错；正式输出才检查**笔顺、方向和抬落笔约束**。模板、多路径点和正式执行校验是本项目补充，不是作者原始代码的精确重现。

## 运行

```bash
conda activate torch-py311
python q_learning_handwriting.py
python q_learning_handwriting.py --strokes examples/H.json --output outputs/H
python -m unittest -v
```

仅依赖 NumPy、Matplotlib；已有 torch-py311 环境可直接运行，不需要神经网络。

## 书写规范

采用 [University of Utah Reading Clinic 的 Letter Formation Suggestions](https://uurc.utah.edu/general/letterformation.php)，固定为 `uurc-print-v1`。英文字母不同教材可能采用不同笔顺，本项目明确执行这一套规则。

| 字母 | 笔顺及落笔方向 |
| --- | --- |
| H | 左竖从上到下 → 抬笔写中横，从左到右 → 抬笔写右竖，从上到下 |
| N | 左竖从上到下 → 抬笔回左上，从左上斜向右下，再不断笔沿右竖向上 |
| A | 从顶点斜向左下 → 抬笔回顶点，斜向右下 → 抬笔写中横，从左到右 |
| O | 左上 → 左下 → 右下 → 右上 → 左上，一笔闭合后抬笔 |

N 为 2 笔（第二笔有转折），A 为 3 笔，O 为 1 笔。O 按用户要求改为四个顶点组成的方框，段间**不抬笔**。四个不同顶点之外，路径末尾重复起点用于闭合，不增加新顶点；此形状是用户指定的简化，不是原教学字帖的圆形 O。`writing_rules.py` 是独立规范模板；`examples/*.json` 读入时必须与模板一致。调换笔画、反转方向、改变路径、未标明规范或未知字符都会被拒绝，不能仅修改 JSON 就绕过规范。

当前只支持已经核对的 H、NAO。旧版未经核对的鼠标录入已禁用；新增字符需要先补充有依据的规范模板，不能把任意用户示范自动认定为正确笔顺。

## 训练与正式执行

状态为 `(已奖励前缀长度k, 当前点编号, pen_down)`。每笔的理想动作是抬笔移动到起点、落笔、沿有向路径写完、终点抬笔。

**训练不屏蔽动作。** 机器人可在错误位置落笔、逆向移动、跳到其他笔或提前抬笔；这些动作都会实际改变仿真位置/笔状态，获得 −1。只有当前状态符合上一目标、动作及新状态符合下一目标时才 +1，并扩展已奖励前缀。出错后保留进度，但必须恢复上一目标的实际位置和笔状态才能继续得分。恢复动作本身也是 −1。这是原文未完整说明处采用的明确实现假设。

`WritingEnv.transition` 是自由试错的环境转移；`validate_trace` 只检查仿真轨迹是否真实连续，允许错误。错误落笔画出的线条也会显示在仿真结果图中，不做隐藏。

**正式输出独立校验。** `validate_execution` 要求从 reset 开始，完整轨迹每一步都严格符合规范动作序列。即使最终完成全部目标，只要过程中有多余试错、逆向、乱序或错误落笔，整个评估轨迹都不得导出为 `trajectory.json`。程序不会删除错误动作后拼出正确轨迹。未通过时会保存拒绝原因，并清除输出目录中遗留的旧执行轨迹。

最终评估从 reset 重新运行贪婪 Q 策略，不执行教师动作、不更新 Q，不在执行时修改错误动作。只有整个评估通过校验，才作为可供后续控制系统使用的轨迹导出。

规范来自教学模板，Q-learning 学习动作选择与错误后的恢复；不具备从图像自行发现任意字符笔顺的能力。

## 实测收敛，不凑论文轮数

当前配置在 `torch-py311` 下运行：α=.5、γ=.9、ε=0，每轮固定执行目标序列长度次动作（H=12步、NAO=28步），结束后重置位置、笔状态和 achieved，保留 Q 表。对 H、NAO 各用 seed=0..4 训练500回合：

| 示例 | 各种子的首次满分回合 | 最终独立评估 |
| --- | --- | --- |
| H | 28、41、23、19、31 | 全部12步、回报12，执行校验通过 |
| NAO | 126、121、131、112、135 | 全部28步、回报28，执行校验通过 |

完整多种子记录在 `outputs/validation_seeds.json`。默认 seed=0 训练1500回合的当前结果在 `outputs/H` 和 `outputs/NAO`。

固定长度限制了每轮的尝试次数，因此有错误的回合无法完成全部目标。**这不是论文约250次序列收敛的精确复现**；原始数据、状态转移与统计口径不足以唯一还原。不会通过减少奖励、修改 ε、裁剪曲线或故意延迟成功来凑250轮。

`first_optimal_episode` 是训练中首次完整且无误的回合；`observed_optimal_tail_start` 是已完成训练记录中最后一次非满分之后的回合，仅描述观察到的末尾连续满分区间，不保证未来永远满分。

## 与论文对应及补充假设

- Q 更新使用论文公式 `Q[s,a] += alpha*(reward+gamma*max(Q[next_s])-Q[s,a])`，真正终止时 bootstrap=0。
- Q 初始化为 0，最大 Q 并列时随机选择，seed 默认 0；ε=0 不排除并列随机。
- achieved 是目标序列的前缀，仅存 k 等价于保存 `target[:k]`。
- 原文只保存起终点。本版为保持正常书写的转折及闭合方向，扩展为每笔多个路径点；含 m 个点的一笔有 m+2 个目标状态。H 理想回报 12，当前 NAO 方框 O 模板理想回报 28（N=9、A=12、O=7）。
- 每回合固定 N=len(target) 步，训练和最终评估使用相同长度。预算耗尽且未完成记为截断；继续沿用原有 Q 更新的时间限制处理，截断仍 bootstrap，只有真正完成全部目标时 bootstrap=0。该固定长度规则是明确选择的复现假设，不能由论文图唯一确认。
- 奖励直接相加，不裁剪、不缩放。H 回报范围 −12～+12；当前 NAO 回报范围 −28～+28。已删除 `--max-steps` 参数，修改字形后长度随目标数自动变化。
- 初始位置取最后一笔终点，笔抬起，初始化不计奖励。
- 共享坐标合并点编号；0=抬笔，1=落笔，2+i=移动到点 i。
- 二维机械臂 L1=0.105 m、L2=0.1137 m，角度顺序为 (RER,RSR)，单位为弧度，检查论文关节范围。逆运动学使用 atan2 保留肩角象限和符号。
- 屏幕原点位于左上，坐标在 [0,1]。映射为 `x=.175+.020*u, y=-.040-.030*v` 米，属于仿真设定，不是实机标定。

## CSV 字段

`episode` 为轮次；`return` 为本轮全部 N 次动作的奖励之和；`steps` 固定为 N；`success` 为全部目标完成标志；`achieved` 为已正确推进的目标状态数。每次 +1 恰好使 achieved 增加1，所以 `return=2*achieved-N`。

固定长度下有一次错误就无法在预算内完成全部 N 个目标，因此 `success=1` 同时意味着 `return=N`、`achieved=N`，与此前2000步上限版本的语义有所不同。

## 文件与输出

- `q_learning_handwriting.py`：环境、Q-learning、运动学、轨迹校验及绘图。
- `writing_rules.py`：规范教学模板。
- `test_q_learning_handwriting.py`：11 项测试，包含固定步数与原始回报边界、失败重置及截断更新、错误动作实际改变状态、错误后恢复、完成但含错误的轨迹拒绝导出、反向/乱序模板、伪造/不完整轨迹、O 四顶点闭合方向及运动学验证。
- `outputs/H`、`outputs/NAO`：重新训练生成的自由试错训练结果。

每次运行输出 `training.csv`、`summary.json`、`q_table.npz`、`results.png`、`evaluation_attempts.json`；整段评估完整且通过严格执行校验时输出 `trajectory.json`。`evaluation_attempts.json` 保存全部评估尝试，包括错误动作，不应下发执行。执行轨迹包含笔画序号、阶段、路径点序号、笔状态、米制坐标和关节角。图中蓝线为落笔移动，橙色虚线为抬笔移动，红色编号及箭头标出笔顺和方向。图中分别提供完整奖励曲线、前50轮原始回报及训练前后路径。训练前图仅展示与理想序列等长的一段策略执行。

未连接真实 NAO，不包含三维落笔姿态、笔尖压力和动力学控制。二维仿真约束保证离散指令顺序，不能替代实机标定和轨迹跟踪验证。
